# «Крапля до краплі — збережемо воду разом!» 💧
> **Шкільний екологічний проєкт 2026 року про збереження прісної води та відповідальне споживання водних ресурсів.**
> Створено у преміальній дизайн-системі **Apple iOS 26 Liquid Glass** з кінематографічною 3D-анімацією води (Three.js), ретро-терміналом MS-DOS та інтерактивним калькулятором економії.

---

## 🌟 Основні можливості проєкту

1. **Кінематографічний вступ (MS-DOS Terminal Boot)**
   - Автентична ретро-заставка з CRT-сканлайнами, люмінофорним світінням, друком команд символ за символом та ASCII-індикатором завантаження.
   - Миттєвий перехід до сцени краплі одразу після завершення друку «SYSTEM READY» та «WATER CONSERVATION PROJECT INITIALIZED» (без пауз, порожніх екранів чи затримок).
   - Одноразовий запуск на основі `localStorage` (`water_intro_seen`).
   - Підтримка пропуску клавішею `[ESC]` або кнопкою та кнопка повторного перегляду «↺ Інтро» в підвалі сайту.
   - Доступність (`prefers-reduced-motion`).

2. **Кінематографічна 2D-крапля води (Motion Design Transition)**
   - Елегантний векторний 2D-силует краплі з багаторівневими градієнтами (`#e0f2fe` → `#38bdf8` → `#0284c7` → `#0369a1`), внутрішнім каустичним світлозаломленням та глянцевим спекулярним бліком.
   - Реалістичне прискорення вільного падіння з аеродинамічною розтяжкою за вектором руху.
   - Відображення краплі у воді, що піднімається назустріч перед зіткненням.
   - Cinematic slow-motion у момент удару об поверхню води.
   - Органічна 2D-деформація краплі (сплющення в лінзу на воді).
   - 34 окремі 2D-краплі сплеску з параболічною траєкторією та 4 концентричні хвилі-кільця з градієнтним світінням.
   - Плавний круговий перехід-маска, що безшовно відкриває сайт.

3. **Візуальний дизайн — Apple iOS 26 Liquid Glass**
   - Справжня багатошарова естетика рідкого скла (`backdrop-filter: blur(28px) saturate(180%)`).
   - Рухомий спекулярний блік та субтильне світлопереломлення на гранях.
   - Плаваюча капсульна навігація (Floating Pill Navigation) з компактним станом при прокручуванні.
   - Типографіка класу SF Pro / Plus Jakarta Sans.
   - Тактильні мікроінтеракції, 3D-нахил карток під курсором (`perspective`).

4. **Інтерактивна 3D-симуляція в Hero-секції**
   - Жива 3D-крапля, що левітує над відбиваючою поверхнею басейну та реагує на рух миші чи дотик.
   - Імпульсна хвиля та пружний відскік при кліку.
   - Незалежні плаваючі віджети: «Мій внесок сьогодні: −24 л води» та «Звичка на краще: Почни з однієї краплі».

5. **Безперервні анімації (Continuous Animations)**
   - Плаваючі віджети рухаються незалежно з різною швидкістю, фазою та траєкторією.
   - Фоновий дрейф неонових орбів та каустичних відблисків.
   - Пульсуюче дихання прозорості скла.
   - Анімовані радіальні кругові індикатори статистики (USGS / EPA).

6. **Адаптивний Scroll Motion Blur & Динамічне матування скла**
   - Розрахунок реальної швидкості скролу ($\Delta y / \Delta t$).
   - Напрямлене розмиття (`--velocity-blur`) виключно для фонових декоративних елементів (текст та елементи керування залишаються кристально чіткими).
   - Динамічний перехід від кришталево чистого рідкого скла до матового при активному русі сторінки.

7. **Інтерактивний калькулятор економії**
   - Вибір щоденної звички (кран, душ, витік, аератор).
   - Степпери тривалості/кількості та людей у родині з миттєвим перерахунком.
   - Вкладки періодів: «День», «Тиждень», «Місяць».
   - 7-денний стовпчиковий графік накопичення води (Пн–Нд) з підсвічуванням пікового значення у неділю.

8. **Повна адаптивність (Responsive Breakpoints)**
   - Desktop (1440px+)
   - Laptop (1024–1439px)
   - Tablet (768–1023px)
   - Mobile (320–767px) — нативний досвід мобільного додатку iOS зі зручним бічним меню (drawer).

## 🛠 Технологічний стек

- **HTML5 & CSS3**: Сучасні CSS Custom Properties, Grid, Flexbox, backdrop-filter.
- **Vanilla JavaScript (ES Modules)**: Модульна архітектура без важких фреймворків.
- **Three.js**: Фізично коректні 3D-симуляції води (`MeshPhysicalMaterial`, `ACESFilmicToneMapping`).
- **GSAP**: Кінематографічні анімації переходів.
- **Vite**: Швидка збірка та HMR для розробки.

## 🚀 Встановлення та запуск

### 1. Передумови
Переконайтеся, що на вашому комп'ютері встановлено **Node.js** (версія 18+ або новіша) та **npm**.

```bash
node -v
npm -v
```

### 2. Встановлення залежностей
Перейдіть до кореневої папки проєкту та виконайте:

```bash
npm install
```

### 3. Запуск у режимі розробки
Запустіть локальний dev-сервер:

```bash
npm run dev
```

Після запуску відкрийте браузер за адресою:
👉 **`http://localhost:5173/`**

### 4. Збірка для продакшну
Щоб згенерувати оптимізований бандл у папці `dist/`:

```bash
npm run build
```

Для попереднього перегляду зібраного проєкту:

```bash
npm run preview
```

## 🌿 Екологічні джерела даних

- **USGS** (United States Geological Survey) — дані щодо запасів прісної води на планеті (~2,5%).
- **EPA WaterSense** — норми витрати води змішувачами та ефективність використання аераторів.
- **Державне агентство водних ресурсів України** — принципи відповідального споживання води в побуті.
